# Soenneker.Constants.CronPresets

Commonly used Cron expressions.

## Install

```bash
dotnet add package Soenneker.Constants.CronPresets
```

## What you get

- `CronPresets` — Commonly used Cron expressions.

## API at a glance

| API | What it does | Result / important behavior |
| --- | --- | --- |
| `CronPresets.StartOfWeek` | Start of every week (Sunday at midnight). | Start of every week (Sunday at midnight). |
| `CronPresets.StartOfMonth` | Start of every month (1st at midnight). | Start of every month (1st at midnight). |
| `CronPresets.StartOfYear` | Start of every year (January 1st at midnight). | Start of every year (January 1st at midnight). |
